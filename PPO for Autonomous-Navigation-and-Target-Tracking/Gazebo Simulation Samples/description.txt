The following samples illustrate the simulation environment used throughout this project.

Robot navigation was developed and trained in Gazebo, which provides a realistic 3D laboratory environment with accurate physics and sensor simulation.

RViz was employed to visualize LiDAR measurements, occupancy maps, robot localization, planned trajectories, and navigation performance in real time.

These simulation environments were used to train, validate, and evaluate the proposed reinforcement learning framework prior to its deployment 

on the Pepper humanoid robot.
